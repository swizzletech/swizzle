# Swizzle documentation

Every page has one mode, and the directory names it. A tutorial teaches by doing. A how-to guide solves one task. A reference page lists facts for lookup. An explanation page says why the platform works the way it does. The owner is the code a page describes: change that code, and check the page in the same change.

`just docs-check` proves the pages in seconds. It fails when a relative link or a linked symbol no longer resolves, when a page under `docs/` is missing from this index, when a generated reference page is stale, or when the shipped `swizzle-builder` skill teaches a command or flag the CLI lacks. `just gen` regenerates the generated pages.
