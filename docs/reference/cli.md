# CLI reference

Generated by `just gen` from [`createProgram`](../../apps/cli/src/main.ts). Edit the source, not this page; `just docs-check` fails when the page is stale. `swizzle commands --json` prints the same tree as JSON, and `swizzle <command> --help` prints one command.

Commands print TOON on stdout, and `--json` prints the same data as one line of JSON. A failing command prints `error`, a stable `code` and `help`, its next steps, and exits non-zero ([`AgentError`](../../apps/cli/src/output.ts)). `swizzle schema error` and `swizzle schema exit-codes` print that contract.

Protected API commands require a configured profile. Without one, they exit 4 with `SIGN_IN_REQUIRED` and the sign-in and token setup steps. The profile is the `--profile` flag, then `SWIZZLE_PROFILE`, then the default profile ([`resolveProfile`](../../apps/cli/src/profile.ts)). The API URL is the `--api-url` flag, then the profile's URL. The environment is the `-e` flag, then the profile's `env`, then `SWIZZLE_ENVIRONMENT` ([`resolveEnvironment`](../../apps/cli/src/profile.ts)). With no environment pinned, commands fail with `ENVIRONMENT_NOT_PINNED`. Local commands and public worker enrollment with a one-use code can run without a profile. Enrollment uses the API URL flag, a selected profile, or the local API default shown below.

These options apply to every command.

| Option | Description | Default |
|---|---|---|
| `-V, --version` | output the version number | - |

| `-e, --environment <name>` | Environment (default: the profile's) | - |
| `--json` | Print JSON instead of TOON | - |
